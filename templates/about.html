باحث الصور - Bahith Al-Suwar

تطبيق بحث عكسي للصور باللغة العربية

الميزات

  • تحميل الصور والبحث عن صور مشابهة عبر Google، Bing، Yandex، وTinEye
  • استخراج إطارات من ملفات الفيديو للبحث عن الصور
  • وش جابك تقرا هنا
  • تصدير نتائج البحث بصيغة JSON
  • تصميم متجاوب للأجهزة المحمولة وأجهزة سطح المكتب

كيفية الاستخدام

  1. انتقل إلى صفحة البحث بالصور
  2. قم بتحميل صورة أو سحبها وإفلاتها في منطقة التحميل
  3. انقر على زر البحث وانتظر حتى تظهر النتائج
  4. استخدم علامات التبويب للتنقل بين محركات البحث المختلفة
  5. انقر على روابط محركات البحث لعرض النتائج الكاملة

التقنيات المستخدمة

  • Python + Flask
  • HTML5 / CSS3 / JavaScript
  • Bootstrap 5
  • OpenCV (لمعالجة الفيديو)
  • API من ImgBB (لاستضافة الصور)

متطلبات النظام

  • Python 3.6+
  • Flask 2.0+
  • OpenCV 4.5+
  • Pillow 8.0+
